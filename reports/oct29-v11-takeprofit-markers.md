# 29 октября: почему не отображался тейк

Источник: публичный API MEXC, SOL_USDT perpetual, Min5, UTC+7. Сохранены закрытые свечи 29.10.2026 до 18:20. Сопоставлены один и тот же участок истории и архив V1 из 39d55db с текущей V1.1.

|Проверка|V1|V1.1|
|---|---|---|
|Исполненный вход|нет|LONG 100,19, свеча 16:40–16:45|
|Стоп|99,91|99,91|
|Цель к концу выборки|100,70, ожидание|100,48, зафиксирована при входе|
|Граница ожидаемого RR1|100,305|вход состоялся по close 100,19|
|Результат|state=1, без входа|TP на свече 17:30–17:35, state=3|

Параметры V1 полностью совпадают с отображением индикатора на скриншоте пользователя. На скриншоте рядом ручной инструмент с входом 100,19 и тейком 100,48, соответствующими исполненной V1.1. Причина различия — механизм входа двух версий: в V1 не было исполненного входа и, следовательно, закрытия по TP; V1.1 уже подтверждает трёхсвечную остановку и выполняет сделку.

Чтобы исключить визуальную неоднозначность, текущая V1.1 показывает «Ожидание» до исполнения и «Вход исполнен» после. Вход отмечается красной точкой на свече и цене исполнения. Выход — красной точкой на модели цены закрытия (TP/SL); TP дополнительно отмечается зелёной галочкой. Время — свеча M5, не установленный по тикам момент внутри неё. Торговые правила TP/SL не изменены. Архив V1 не менялся.
