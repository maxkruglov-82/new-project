Каждый фактический вход считается отдельной сделкой. Стоп и последующий тейк одного дня не объединяются. Сетапы «Без входа» не входят в сделки. Винрейт=TP/(TP+SL); открытые позиции исключены из знаменателя. Сделка относится к месяцу входа; выход может находиться в следующем месяце.

Использован полный опубликованный код с исходными настройками, без удаления графических блоков и без правок торговой логики. Первый час Лондона08–09 Europe/London:14–15 летом и15–16 зимой в Красноярске. Вход по касанию RR1:1, стоп по телу, тейк по тени, SL имеет приоритет при обоих исходах на одной последующей M5. Выход на свече входа не моделируется. Результат представляет модель исполнения по M5.

Для каждого входа независимо проверены касание цены тенью, RR и отсутствие нарушения стопа телом; для каждого выхода проверен исход по OHLC. В каждой месячной выборке семь дней контекста слева и до семи дней справа; результаты первой недели следующего месяца сверены между соседними прогонами, переносы позиций проверены. Пропусков данных нет.

Известное ограничение реализации: ошибка14 октября — после отклонения ранней встречной тройки состояние может оставаться завершённым и блокировать последующую внешнюю структуру. Контрольный сценарий пользователя14 октября: исходное0→1 вверх, затем внешний LL около106.24 → LH107.82 ниже исходной1=108.45 → новый LL104.61; далее ретест, стоп заLH. Опубликованный код этого входа не сформировал. В этом бэктесте ошибка НЕ исправлялась. Поэтому числа относятся к опубликованному кодуe7f6d3f, а не к предполагаемой исправленной стратегии.
