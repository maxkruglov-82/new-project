## Проверка расчёта

Каждый месяц выполняется отдельно с семидневным разогревом и просмотром семи дней после месяца, ограниченным концом данных. Межмесячные входы, уровни и известные исходы совпали. Касание RR1:1 и TP/SL независимо проверены поOHLC: вход тенью по точному уровню, SL по телу, TP по тени, при одновременном SL/TP приоритет SL. Выход на свече входа не моделируется. Не более двух фактических входов за день, второй только после первого SL.

Набор исходных свечей общий с предыдущим отчётом: `../backtest-2026-body-confirmed-extremes/input.json.gz`. SHA256 проверяется после распаковки. Новая ветка по12 октября отложена и не включена. Изменения визуальных инструментов не меняют финансовые сигналы; это отдельно проверено на22/23 октября и зеркальных вариантах.
