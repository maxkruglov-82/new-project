Дней SL→TP: 19; оба входа учтены раздельно. При одинаковом риске результат 13R до комиссий и проскальзывания. Ожидания без входа не считаются сделками. Незавершённые входы не включены в долю TP.

Модель: два последовательных касания одного RR1; стоп по телу M5, тейк по тени; при обоих событиях на одной свече приоритет SL. Выходы проверяются со следующей свечи после входа. Каждое исполнение независимо проверено по OHLC. Месячные прогоны имеют два дня разогрева и следующий день для проверки выходов. Результат относится к модели индикатора, без порядка тиков внутри M5.

Исходник: indicator.txt; его SHA256 и SHA256 данных указаны в summary.json. Все входы: trades.csv / trades.json.
