# Переносы 0 и 1 после неудавшегося закрепа

Источник: сохранённые реальные MEXC SOL_USDT perpetual, M5. Время Красноярска UTC+7; метки открытия M5. Проверено через PineTS, не в интерфейсе BingX.

## Правило

За всеми сформированными уровнями, включая 1, нужны два последовательных close M5 минимум на 0.01 за одним старым уровнем. Только первоначальный выход за границу часа остаётся односвечным. Первая свеча за уровнем не переносит его и не даёт ретроспективный вход. Если вторая не подтверждает — переносим 0 или 1 на экстремум тел попытки, при равенстве на последнее повторение. Два закрытия подтверждают уровень и запрещают такой перенос.

Переносы разрешены только до первой сделки и до действительной смены тренда за 0. Неисполненный сценарий удаляется, исполненные сделки остаются неизменны. При переносе 1 ждём новый пятисвечный откат; глубокий противоположный кандидат сохраняется, более мелкий не подменяет его. При переносе 0 прежний ошибочный хай 2 становится 0, следующий лой получает номер 2. Сам способ начального поиска кандидатов 0 не изменён.

## 1 октября

| Событие | M5 | Цена |
|---|---|---:|
| Первоначальная 0 | 16:35 | 118.02 |
| Первый close выше старой 0 | 17:50 | 118.15 |
| Второй close не подтвердил: перенос 0 на последнее повторение high | 17:55 | 118.15 |
| Сохраняем 1 | 17:00 | 117.01 |
| SHORT на ретесте | 20:30 | 117.39 |
| Стоп за новой 0 | — | 118.15 |
| Цель, метка 2 | — | 116.84 |
| TP | 22:05 | по тени |

RR по фактическому close входа 1:0.72: касание RR1 тенью с входом по close может дать RR ниже единицы, как в ранее согласованном правиле. Нисходящий тренд при неудачной попытке не меняется. Начало окраски остаётся на прежней 0, поэтому перенос метки не стирает старый участок.

## 21 октября

| Событие | M5 | Цена |

| Первоначальная 1 | 15:45 | 107.00 |

| Глубокая опора 2 сохраняется | — | 106.01 |
| Два close за сформированной 1 | 20:00, 20:05 | подтверждено |
| LONG на ретесте | 20:30 | 106.42 |
| Стоп / цель | — | 106.01 / 107.50 |
| RR по фактическому close | — | 1:2.63 |

После двух закрытий 1 не переносится на 107.50: это новая цель, а не неудачный пробой. До подтверждения 0 вход в SHORT не разрешён.

## Изменившиеся старые примеры

22 октября: односвечный ранний пробой 1 теперь переносит её на 103.64 / 16:05. Прежнего SHORT 16:05 и повторного LONG 16:20 нет. Поздний первый LONG после действительного пробоя 0: 20:05 по 104.14, стоп 103.64, цель 104.67, TP 20:25.

16 октября, пятница: первый LONG 19:00 → SL 19:45, новая структура и второй LONG 21:50 → SL 22:05. Противоположного входа в пятницу и третьей сделки нет.

12 октября: неудачная ранняя попытка переносит 1; после подтверждения двумя свечами цель сопровождает новые минимумы. SHORT 17:45 → TP 18:00 сохраняется.

## Проверки

Общая серия indicator-tests/open-close-current.mjs прошла. Отдельно проверены реальные примеры 1 и 21 октября, зеркальные преобразования OHLC с заданным исходным уровнем для проверки механизма переноса, отказ от переноса при двух подтверждающих свечах, ожидание пяти свечей после переноса 1, сохранение глубокой опоры, отсутствие переписывания исполненной сделки и ограничение двух сделок в день.

Прогон 34 560 M5 за 120 дней прошёл: результат стабилен при добавлении старой истории, рисунки ограничены, междневных диагоналей нет. Старые версии отчётов с односвечным исключением за сформированной 1 описывают прежний алгоритм.
