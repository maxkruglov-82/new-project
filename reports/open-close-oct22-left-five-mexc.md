# MEXC, 22 октября: фильтр пяти свечей слева для high 0

Реальные SOL_USDT perpetual M5 из сохранённого ряда MEXC. Проверка не использует котировки BingX.

- До фильтра: 0 = 105.01, 13:00; SHORT 17:00 → SL 20:30, LONG 21:30 → SL 23:45.
- После фильтра: 0 = 104.57, 14:00. Все пять непосредственно предыдущих тел M5 имеют high не выше 104.57.
- SHORT 16:50: вход 104.11, стоп 104.57, цель 103.64; SL в свече 17:30.
- LONG 20:05: вход 104.14, стоп 103.64, цель 104.67; TP в свече 20:25.

Все времена Красноярск UTC+7 и обозначают открытие M5; вход по close соответствующей свечи. По правилу группировки пользователя день SL+TP считается одним успешным днём; фактически исполнены две сделки.

Тест: `node indicator-tests/open-close-oct22-left-five.mjs`. Отдельные проверки `open-close-origin-left-five.mjs` подтверждают пять/четыре свечи, равные максимумы, отсутствие шестой свечи в фильтре, разрывы истории, исключение кандидатов до 13:00, отсутствие влияния правых свечей и сохранение прежнего выбора low 0.

Позднейшее уточнение пользователя вернуло стоп за откат 2 в структуре 1–2–3. Результаты этой версии пересчитаны: актуальный контроль — `reports/open-close-oct12-pullback-stop.md`. Цифры выше сохраняются как отчёт о предшествующей версии.
