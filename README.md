# Учебный Telegram-бот Макса

Бот на Python отвечает на сообщения:

- `/start` — «Привет, Макс, я твой бот.»
- `/help` — объяснение команд.
- `/price` — текущая цена одного BTC в USDT на спотовом рынке MEXC.
- `/change` — запрашивает сумму в рублях и рассчитывает необходимое количество BTC.
  Принимает, например, `100000`, `150 000`, `300 тысяч`, `100 тыс.` и суммы
  с копейками. Неверный ввод можно повторить; `/start` отменяет ввод суммы.
  Сумма временно хранится для пользователя до перезапуска бота.
- Обычный текст — «Ты написал: …» с повторением исходного сообщения.

В личном чате с ботом команды доступны по кнопке «Меню» рядом с полем ввода.
При каждом запуске программа регистрирует `/start`, `/help`, `/price` и `/change`
с русскими описаниями и включает стандартное меню команд Telegram.
Если меню не обновилось сразу, закройте и снова откройте чат с ботом.

Длинный ответ разбивается на несколько сообщений в пределах лимита Telegram.
Неизвестные команды и нетекстовые сообщения игнорируются.

Команда `/price` при каждом вызове запрашивает последнюю цену сделки пары
`BTCUSDT` через публичный API MEXC:
`https://api.mexc.com/api/v3/ticker/price?symbol=BTCUSDT`.
API-ключ MEXC не нужен. Цена выводится с двумя знаками после точки.
В ответе указано время получения данных по Красноярску (UTC+7), а не время
сделки. Цена может измениться сразу после ответа. При недоступности MEXC
бот предлагает повторить команду позже, не подставляя старую или выдуманную цену.

Команда `/change` считает по формуле:

```text
Сумма с наценкой = рубли × 1,085
USDT = сумма с наценкой / курс RUB за 1 USDT (CoinGecko)
BTC = USDT / цена BTC в USDT (MEXC)
```

Для USDT/RUB используется публичный API CoinGecko:
`https://api.coingecko.com/api/v3/simple/price?ids=tether&vs_currencies=rub&include_last_updated_at=true`.
Это рыночная оценка USDT в рублях, а не предложение конкретного обменника или P2P.
Курс должен быть положительным и обновлённым не более пяти минут назад.
Итоговое количество BTC округляется вверх до восьми знаков, промежуточная
сумма USDT перед расчётом BTC не округляется. В ответе показаны исходная сумма,
сумма с наценкой, оба курса и время получения по Красноярску (UTC+7).
При недоступности одного из источников результат не выдаётся; можно отправить
сумму повторно или отменить ввод командой `/start`.

## Установка

Нужны Python 3.10 или новее и доступ к PyPI для установки зависимостей.
В терминале Linux/macOS из папки репозитория выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows активируйте среду командой `.venv\Scripts\Activate.ps1`
в PowerShell, затем выполните ту же команду установки через `python -m pip`.

## Проверка без настоящего токена

```bash
python -m unittest -v test_bot
```

Тесты проверяют ответы, регистрацию меню и обработчиков, фильтрацию команд,
длинные сообщения, чтение `BOT_TOKEN`, ввод рублей, расчёт и ошибки API MEXC и CoinGecko.
Ответы Telegram, MEXC и CoinGecko заменены заглушками; настоящий токен и доступ
к сети не нужны.

## Безопасное добавление токена

Получите токен своего бота у официального `@BotFather` в Telegram.
Бот читает его только из переменной окружения `BOT_TOKEN`.

В облачной среде добавьте значение в защищённое поле **секрета** `BOT_TOKEN`
в настройках среды, разрешив назначение `api.telegram.org`. Примените настройки
перед запуском. Если платформа использует прокси для секретов, для запуска
необходима совместимость этого прокси с Telegram Bot API.

Для локального запуска в Bash введите токен скрыто, без записи его значения
в команду и историю терминала:

```bash
read -r -s -p 'BOT_TOKEN: ' BOT_TOKEN
printf '\n'
export BOT_TOKEN
python bot.py
```

Не отправляйте токен в чат, не вставляйте в код и не коммитьте в Git.
`.env`, файлы ключей и типовые файлы секретов исключены через `.gitignore`.
Файл `.env` автоматически не загружается. Если токен стал доступен посторонним,
отзовите его через `@BotFather` и задайте новый в настройках секретов.

## Запуск и ручная проверка

После установки зависимостей и задания `BOT_TOKEN`:

```bash
python bot.py
```

Бот работает через polling; входящий порт и веб-сервер не нужны.
Требуется исходящий HTTPS-доступ к `api.telegram.org` и
`api.mexc.com` и `api.coingecko.com`. Запускайте только один
экземпляр для одного токена. При старте polling библиотека автоматически
отключает ранее установленный webhook.

Откройте своего бота в Telegram и проверьте `/start`, `/help` и сообщение
`Привет` — ожидаемый ответ на последнее: «Ты написал: Привет».
Затем отправьте `/price`: бот должен ответить ценой BTC/USDT на MEXC
и временем получения котировки.
Выберите `/change`, введите сумму в рублях и проверьте вывод расчёта с обоими курсами.
Для остановки нажмите `Ctrl+C`. Без `BOT_TOKEN` программа завершается
с понятным сообщением до обращения к Telegram.
