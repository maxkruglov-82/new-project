# KRYTES v72 — 26 октября 2026

Исходник: `KRYTES_v72_REVERSAL_UPDATED.txt` (Pine Script v5).
`KRYTES_v72_TWO_M5_CLOSES.txt` содержит ту же опубликованную v72.
В течение этого дня изменения сохраняются в v72 по команде пользователя.

- Свеча, одновременно образующая локальные хай и лой, не используется как структурный пивот.
- Закреп — два последовательных закрытия M5 за уровнем; пропуск M5 прерывает пару.
- Начальная 1Sh/1L формируется после закрепа за соответствующей границей H1; учитывается тень первой свечи пары.
- Свеча 2Sh/2L — минимум третья после свечи 1; сама свеча 1 не считается.
- Новый экстремум 1 без подтверждённого закрепа сбрасывает старую 2 для продолжения структуры: ждём новый откат.
- После обновления минимума 1Sh прежняя 2Sh сохраняется отдельно для разворота. Два закрытия выше неё подтверждают 3Sh и поиск LONG на откате. Без обновления минимума этот специальный сценарий не включается.
- Два закрытия ниже прежней 1Sh подтверждают продолжение SHORT со старой 2Sh.
- В LONG-структуре сохраняются исходный high 1L и low отката. Обновление high без двух закрытий выше исходной 1L не подтверждает LONG. После такого ложного верхнего пробоя два закрытия ниже сохранённого low отката подтверждают SHORT; стоп — за обновлённым high, цель — low третьей точки, вход — на ретесте с RR 1:1. Подтверждённый сетап не сбрасывается из-за повторного закрепа на нижней стороне H1.
- Если первой подтверждена LONG-сторона и нижняя сторона H1 не была подтверждена, обычный откат ниже промежуточной 2L сам по себе не даёт SHORT. Сценарий разворота после обновления high рассматривается отдельно, как описано выше.
- После обновления 1Sh тенью исходная 2Sh сохраняется как уровень разворота. Ложный выход выше неё без двух закрытий не создаёт новую 2Sh. Повторные обновления 1Sh не теряют сохранённый уровень 2Sh.
- Входы разрешены строго до 22:00 по Красноярску (UTC+7), включая свечу 21:55. Начиная с 22:00 новые сделки не открываются; уже открытые сопровождаются до цели/стопа. Прежнее ограничение первой сделки в 20:30 снято.
- Для продолжения основной LONG-структуры исходная 1L сохраняется как уровень подтверждения через внутренние движения отката. При двух закрытиях выше неё 2L ставится на самый низ всего отката, включая тени; 3L — новый максимум, вход — только на последующем ретесте середины между стопом и целью. Обозначения остаются 1L/2L/3L.
- Контекст продолжения LONG отменяется при двух закрытиях ниже нижней границы H1, после состоявшегося входа или по окончании окна; новая опорная H1 сбрасывает контекст.
- Дополнительные сделки по подструктурам пока не добавлены: отдельные торговые правила для них не согласованы.
- Стоп за опорным свингом с настраиваемым отступом (по умолчанию 0,03 USDT), цель — экстремум 3; вход посередине между стопом и целью, RR 1:1. До входа обновление экстремума 3 пересчитывает цель и вход.
- Маленькие оранжевые подписи активной структуры: 1Sh/2Sh/3Sh и 1L/2L/3L. При развороте сохраняются обозначения исходной структуры. Подписи обновляются вместе с точками; сброшенная 2 скрывается. Архив отдельных подписей предыдущих структур не добавлен.

## Уточнение внутренних структур 3–4 августа

- После 2Sh ищется локальный low отдельного отката (минимум третья свеча после 2Sh). Два последовательных закрытия M5 ниже него подтверждают внутренний SHORT: пробой первоначальной 1Sh не требуется.
- Закреп сам по себе не даёт вход. Пока ретест не достиг входа, новый минимум обновляет цель и середину RR 1:1; стоп остаётся за опорной 2Sh с настроенным отступом. Обязательного числа отдельных закрепов нет.
- После отката из минимум трёх свечей выше первоначальной 1Sh два закрытия выше 2Sh подтверждают LONG. Обновление исходного low 1Sh для этого сценария не требуется. Стоп — за low данного отката, вход — на следующем ретесте RR 1:1.
- Ложное превышение 2Sh без двух закрытий не переносит уровень подтверждения после появления локального low отката.
- Максимум две сделки под одной опорной H1; вторая только после стопа первой, после тейка новых входов нет. Ограничения строго одной сделки в день нет.
- 03.08.2026, 288 свечей: один SHORT в 18:20, вход 72,57, стоп 72,80, цель 72,34; тейк в 19:05.
- 04.08.2026, 288 свечей: один LONG в 19:15, вход 73,73, стоп 73,48, цель 73,98; тейк в 19:35. Для этого LONG после повышенного лоя вход рассчитывается по исходным уровням без отступов: (low отката + high третьей точки) / 2. Стоп = low отката − stopOffset, тейк = high третьей точки + stopOffset. По умолчанию stopOffset = 0,03; фактическое RR остаётся 1:1. До входа обновление high пересчитывает базовый вход и расширенный тейк; после входа уровни заморожены. Изменение не распространяется на остальные типы сетапов.
- 08.10.2026: первая сделка по стопу, затем вторая по тейку; обе сохранены.

Ранее опубликованная помесячная статистика 2026 года относится к предыдущему SHA256 v72. После этих изменений годовой прогон не повторялся; прежние числа нельзя считать статистикой обновлённого кода.

## Вторая сделка после стопа: 10 августа

После стопа LONG, сформированного по откату выше исходной 1Sh, восстановление SHORT использует сохранённую исходную 1Sh и максимум предыдущего LONG. Оно не подменяет 1Sh более высоким low отката. Сохранённая SHORT-структура также может восстанавливаться после первой сделки, если она закрылась по стопу; до этого восстановление было ошибочно ограничено условием «сделок ещё не было». Сам по себе стоп не является сигналом: нужны два закрытия за структурным уровнем и последующий отдельный ретест.

Проверены 288 M5 свечей 10.08.2026: LONG в 19:25 по 76,86, стоп 76,60 в 19:55; два закрытия ниже исходной 1Sh 76,50 подтверждают SHORT в 20:35. Второй вход на ретесте в 21:10 по 76,61, стоп 77,12, цель 76,10; тейк в 22:10. Фактических сделок ровно две; третий вход запрещён. Открытая до 22:00 сделка сопровождается и после 22:00.

## Обновлённая 1L и SHORT 5 августа

Подтверждение продолжения LONG при активной LONG-структуре проверяет актуальный high 1L: максимум сохранённого опорного high и текущей обновлённой точки. Более низкий устаревший уровень не может подтвердить LONG или отключить ожидаемый SHORT. При подтверждении сохраняются цена и время именно выбранной актуальной 1L.

Для SHORT после ложного верхнего пробоя вход рассчитывается по исходному свингу без отступов: (опорный high + текущий low третьей точки) / 2. Стоп = high + stopOffset, тейк = low − stopOffset. По умолчанию отступ 0,03; фактическое RR остаётся 1:1. До входа новый low обновляет базовый вход и расширенный тейк; после входа уровни фиксированы. Остальные типы SHORT этим правилом не изменяются.

05.08.2026, 288 M5 свечей: ложный LONG по старой 1L 74,08 исключён (актуальная 1L уже 74,13). Закреп ниже low на свечах 17:45 и 17:50 подтверждает SHORT; вход на ретесте в 18:05 по 73,965, стоп 74,20, цель 73,73; тейк в 18:30. Фактическая сделка одна.

Сохранена ранее исправленная вторая сделка 10 августа: LONG → стоп → SHORT → тейк. Помесячная статистика требует нового прогона для этого обновления; ранее рассчитанные таблицы относятся к прежнему SHA256.
