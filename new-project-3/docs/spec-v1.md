# Версия 1 — H4/M15, SOL/USDT Binance

Версия 1 — публикация от 23 октября 2026 года по команде пользователя.

## Опорный диапазон

SOL/USDT Binance USDT perpetual futures. Опорная H4: 11:00–15:00 Asia/Krasnoyarsk (UTC+7), то есть 04:00–08:00 UTC. Индикатор собирает её из 16 последовательных полностью закрытых M15. Если свеча пропущена, неполная H4 не публикуется. Рабочий график — M15; свеча 15:00–15:15 уже участвует в поиске.

## Структура 1–2–3

Алгоритм заменяет ранее обсуждавшийся вход от первого свинга с опорой на границу H4 для обоих направлений.

Для лонга:

1. Строгий пробой верхней H4 задаёт приоритет LONG.
2. Подтверждается свинг-хай P1, затем свинг-лой отката P2. Соседние свечи P1/P2 пропускаются: между ними нужна хотя бы одна свеча.
3. Новый максимум строго выше P1 даёт P3.
4. Фибо строится по P2–P3: уровень 1 на P2, уровень 0 на P3. Стоп — один минимальный тик ниже P2; тейк — P3.
5. Вход E = (2 × SL + TP) / 3 даёт расстояние до тейка вдвое больше риска. Вход ожидается на отдельном последующем ретесте.

Для шорта зеркально: пробой нижней H4 → свинг-лой P1 → свинг-хай P2 → строгий пробой P1 вниз с P3. Фибо 1 на P2, 0 на P3; стоп один минимальный тик выше P2, тейк P3, та же формула входа.

Шаг цены берётся из `syminfo.mintick`. Фиксированных отступов 0,02/0,03 нет. Уровни Фибо −0,25 и 1,25 вспомогательные; стоп определяется P2 и одним тиком.

## Смена приоритета

До входа при лонговом приоритете цена не должна строго пересекать нижнюю H4. Если пересекает, прежняя структура отменяется и начинается поиск шорта. Касание допустимо. Для шорта зеркально: пересечение верхней H4 переводит поиск в лонг.

Открытая позиция сопровождается до фиксированного стопа или тейка. После фактического стопа приоритет становится противоположным. Новый вход требует новой структуры 1–2–3 и отдельного ретеста; мгновенного рыночного переворота нет. В реализации обратная структура ищется начиная со следующей M15 после стоповой свечи. Новый пробой H4 для этой смены после стопа не требуется.

После смены по стопу уже состоявшееся пребывание цены за H4 не переключает приоритет обратно. Для следующей смены по H4 требуется новое пересечение противоположной границы.

## Детали и границы реализации

- P1/P2 подтверждаются закрытой правой свечой. Используется строгий трёхсвечный экстремум: high выше обоих соседних high либо low ниже обоих соседних low. Обработка равных экстремумов отдельно не согласована.
- Пока P2 не определена, более крайняя подтверждённая P1 переносит первую точку. До пробоя P1 более глубокая подтверждённая P2 обновляет вторую точку.
- P3 — экстремум закрытой свечи пробоя P1. Если эта свеча одновременно подтверждает P2, план появляется после закрытия; вход на этой же исторической свече не дорисовывается.
- Первый рассчитанный план фиксирован. Поведение при новом экстремуме P3 до входа отдельно не согласовано; автоматическое перемещение Фибо не включено.
- Формула даёт точный математический RR 1:2. Округление входа до биржевого шага не добавлено. Это индикатор, не исполнитель ордеров.
- Исторический ретест засчитывается на следующей свече или позже при подходе к входу с нужной стороны. В реальном времени проверяется пересечение текущей котировкой.
- Если на последующей исторической M15 задеты и SL, и TP, исход неопределённый, автоматической смены приоритета нет. Порядок касаний на исторической свече самого входа по M15 не восстанавливается; её экстремумы для исхода не используются. Для достоверной статистики таких случаев нужны младшие данные.
- Ожидающий план действует до новой завершённой опорной H4, которая заменяет его. Открытая позиция сохраняет свои цены до исхода.
- После тейка повторный поиск под той же H4 не добавлен. Время окончания поиска, фильтр выходных и дневной лимит попыток не согласованы и не перенесены из M5.

## Проверка

Контрольные тесты исполняют Pine-код через PineTS: сбор H4, структура 1–2–3, исключение соседних P1/P2, зеркальные направления, тик 0,01 и 0,001, RR 1:2, ретест, смена приоритета по H4 и после стопа, сохранение открытой позиции и неопределённые исходы. Исторический бэктест и проверка интерфейса Krytes сюда не входят.
