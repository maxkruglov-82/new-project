# Проект 3 — SOL/USDT Binance, H4 + M15, RR 1:2

Версия 1 — публикация от 23 октября 2026 года по команде пользователя.

Это самостоятельная стратегия со своей нумерацией v1, v2 и далее. Solana M5 v32 и NEAR относятся к проекту 2. Их правила не наследуются; изменения проекта 3 не меняют проект 2.

Опорная H4 — 11:00–15:00 по Красноярску (UTC+7). Рабочий график — SOL/USDT Binance Futures, M15. После пробоя строится структура 1–2–3, Фибо по точкам 2–3 и план ретеста с RR 1:2. До входа пересечение противоположной границы H4 меняет приоритет; после стопа начинается поиск обратного сетапа.

Проверки: `npm install` и `npm test` (Node.js 24+, PineTS 0.12.0). Тесты исполняют сам Pine-исходник на контрольных свечах с заданным минимальным тиком. Они не заменяют проверку загрузки в Krytes и исторический бэктест. Статистика M5 сюда не относится.
