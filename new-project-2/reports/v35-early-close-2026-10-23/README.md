# Solana M5 v35 — исключение для обеих ранних свечей

Основа — опубликованная Solana M5 v34. Публикуется по команде пользователя от23 октября2026. Проект H4/M15 и NEAR не менялись.

Пользователь подтвердил: исключение действует для обеих свечей 15:00–15:05 и 15:05–15:10 по Красноярску UTC+7.

## Правило

Пока первоначальный приоритет не выбран, ранняя M5 может задать его только после фактического закрытия:

- SHORT: close строго ниже нижней H1, а low прошёл прежний минимальный порог пробоя 0,02 USDT включительно.
- LONG: close строго выше верхней H1, а high прошёл тот же порог зеркально.
- Закрытие внутри диапазона или ровно на границе не разрешает ранний пробой. До закрытия выход текущей котировки за границу недостаточен.
- Дополнительного требования закрыться на 0,02 за границей нет: прежний порог относится к экстремуму, а закрытие должно быть строго снаружи.
- Если ранняя свеча имеет тени по обе стороны H1, первоначальное направление выбирается по стороне закрытия. Её прежние тени не используются как последующая обратная отмена: право на первоначальный приоритет стало известно только после закрытия.
- После выбора приоритета остальные механизмы v34 действуют как прежде. Свинг P1 подтверждается правой свечой; закрытие ранней M5 само по себе не отменяет требование подтверждения свинга и не является входом.
- Начиная со свечи15:10 обычный пробой тенью разрешён по прежним правилам, требования закрыться за границей нет.

Структура1–2–3, обновления P2/P3, отдельный ретест, базовыйRR1:1, прежние SL/TP буферы0,03 и остальные правила v34 сохранены.
