# NEAR/USDT Binance — стратегия v32

Отдельный индикатор для Krytes. Исходная логика — точная Solana v32, без BAG1–3 из отклонённой v33. Изменены только название и указание актива/биржи; вычисления и настройки совпадают.

Загрузить `near_setup.txt` на график **NEAR/USDT, Binance, USDT perpetual futures, 5 минут**. Свечи поставляет выбранный график; индикатор не переключает биржу автоматически. На другом таймфрейме он выдаёт поясняющую ошибку.

Опорный час14:00–15:00 по Красноярску UTC+7; поиск с15:05 до00:00 по будням. После тейка новых входов нет. Стратегия1:1 до отступов; порог пробоя часа0.02USDT, стоп заФибо0.03USDT, тейк перед целью0.03USDT. Эти величины абсолютные, перенесены без масштабирования сSOL по просьбе пользователя. Все остальные правила v32 сохранены, в том числе запрет обычного входа по соседним свингам и разворотное исключение.

Это индикатор разметки и оповещений; торговые ордера не отправляет. Бэктест Solana наBinance не является результатом NEAR. Историческая статистика NEAR пока не рассчитана.
