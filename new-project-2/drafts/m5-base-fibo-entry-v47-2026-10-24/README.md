# Solana M5 v47 — согласованные изменения

Исходник sol_base_fibo.pine/.txt соответствует публикации, отличается только пометкой «черновик»/«проверка» в названии. Предыдущая v46 сохранена в tests/fixtures/sol-v46-published.pine и неизменном Git-коммите6de0f04.

## Торговые условия

H1:14:00–15:00, M5, рабочие дни, Asia/Krasnoyarsk. Максимум2 входа за дневной H1. Второй после SL — противоположный; после установленного TP — любой новый сетап. Вход второй сделки после закрытия первой, не на той же M5. Вход до23:59; M5, закрывающаяся в00:00, не подходит. Нет обязательного закрытия позиции в23:59: ограничен поиск входа.

Для направления d=+1 LONG/-1 SHORT: базовый SL=P2−0.25×(P3−P2), фактический SL=базовый SL−d×0.01. TP=P3. Порог входа=(базовыйSL+TP)/2. LONG close≤порог; SHORT close≥порог. Исполнение — фактический close подтверждённой ретестовой M5, на следующем отдельном движении после P3. Stop не должен уже быть затронут на входной свече. Вход не пересчитывается из-за защитного отступа; фактический RR может быть немного ниже1. До входа P3 и расчёты двигаются по экстремумам; после входа SL/TP фиксированы.

Нейтральная соседняя пара разрешает только обратный план после close за точкой2. Однократная проверка первой пары после первого подтверждённого выхода в каждую сторону, сброс только на новой дневной H1. Последующие самостоятельные свинги остаются допустимыми P2. У второй сделки после TP используется отдельный кандидат структуры: он формируется во время первой позиции без изменения её ордерных уровней; вход только после её TP. Прокол P1 без close переносит P1: дальнейший close сравнивается со свежим экстремумом.

## Проверки

check-formulas.mjs — зеркальные направления, отступы0.01/0.10 не меняют базовый порог, разрешён фактический RR<1 на пороге, реальные16октября.

check-features.mjs — вторые сделки после TP в ту же/обратную сторону зеркально; точки во время первой позиции; фиксация её SL/TP; отсутствие входа на баре TP и третьего входа; нейтральная соседняя пара; однократность флагов до новой H1; перенос P1 после прокола.

check-close-entry.mjs — реальные23октября, зеркальный LONG, открытая M5 не даёт входа, после close событие одно. Новые условия дают SHORT по close21:35=104.57, фактическое время входа21:40. Старую ручную последовательность LONG SL→SHORT нельзя обещать при других правилах исполнения.

run-halfyear.mjs — точный Pine по52 536 M5 MEXC23апреля–22октября2026; audit.py независимо проверяет входы, подтверждения, SL/TP и первый последующий выход по исходным OHLC. Незавершённые/неоднозначные исходы исключены из винрейта. R без комиссий, проскальзывания, funding и без удвоения объёма. Годовой прогон v47 ещё не выполнен.

Наблюдение разделено: Detection — свинги и подтверждения, Validation — закрытие/порог/лимиты, Rendering — объекты. Диагностические plot: Initial Short/Long Pair Used, After TP Search, TP Shadow Stage/Direction/Confirm Bar/Break Level/Break Close. Отсутствие линии не является доказательством отсутствия рассчитанного события.

Проверки выполнены в PineTS, не в реальном TradingView/Krytes. Статус — проверка на графике. Результаты предыдущих версий не являются результатами v47.

Контрольный результат23апреля–22октября2026: 146 входов, 50 TP, 91 SL, 5 незавершённых; винрейт 35.46%. Это проверка механики текущего варианта, не улучшение доходности.
