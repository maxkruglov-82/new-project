# Интерфейс пользовательских индикаторов Krytes

Источник: скриншот окна «Новый скрипт», присланный пользователем 20.10.2026.
Это описание заявленных в интерфейсе возможностей, а не результат запуска кода.

## Загрузка

- Терминал на скриншоте: `trading.krytes.ru`.
- Окно содержит название скрипта, выбор цвета, поле «Код (Pine или JS)»
  и кнопку «Загрузить .txt».
- В подсказке указаны Pine Script v4–v6 и JavaScript.
- Для Pine в интерфейсе отмечено отсутствие поддержки `strategy.*`,
  бэктеста и данных не о цене — отчётности компаний и экономики.

## JavaScript

Согласно подсказке, скрипт — функция от `(ohlcv, helpers)`,
возвращающая массив точек `[{time, value}]`.

`ohlcv` — массив свечей:

```text
{time, open, high, low, close, volume}
```

`time` указан как время в Unix-секундах.

Перечисленные помощники:

```text
helpers.sma(period)                  → [{time, value}]
helpers.ema(period)                  → [{time, value}]
helpers.rsi(period)                  → [{time, value}]
helpers.atr(period)                  → [{time, value}]
helpers.stdev(period)                → [{time, value}]
helpers.macd(fast, slow, signal)      → {macd, signal, hist}
helpers.bb(period, mult)             → {basis, upper, lower}
```

По подсказке невалидные точки автоматически отбрасываются.
Контракт отрисовки нескольких серий, меток и зон на этом скриншоте не описан.

## Выбор для данного проекта

Выбран Pine Script v5: алгоритму нужны несколько уровней, прямоугольники,
метка SHORT и условие оповещения. Показанный JS-контракт описывает только
одну серию `{time, value}` и не документирует эти возможности.

Повторный скриншот пользователя от 20.10.2026 подтверждает подсказки редактора.
Алгоритм согласован отдельно в [current-spec.md](current-spec.md).
Публичная страница Krytes из рабочей среды недоступна: прокси возвращает 403.
Наличие Pine в подсказке не доказывает реализацию всех функций Pine
конкретным движком терминала. Проверка в редакторе остаётся следующим
этапом, особенно для `box`, `varip`, `plotshape`, `alertcondition`.
