## v14 — стоп на 0.03 USDT за Фибо, вход как прежде

Пользователь явно уточнил: сдвигается только SL, E не пересчитывается
по новому SL. Поэтому базовая линия хранится отдельно как stopFibo,
E=(stopFibo+T)/2; SL=stopFibo+0.03 для SHORT и −0.03 для LONG.
Линии Фибо не сдвигаются. Прежний фильтр SHORT проверяет базовую линию.
Подпись позиции показывает фактический reward/risk, а не фиктивный 1:1.

137 проверок, 0 ошибок: 130 индикатора и 7 журнала. Прежние сценарии
структуры прогоняются с документированной настройкой отступа 0, чтобы
выделять регрессии. Шесть новых зеркальных проверок исполняют исходник
без переопределения настроек, с настоящим default 0.03: прежняя середина
по-прежнему даёт вход, касание красной линии без 0.03 не даёт стоп,
касание фактического SL даёт стоп; перенос Фибо 2–3 сохраняет отступ.
Семь тестов журнала также используют default 0.03 и проверяют фактические
R, включая прибыль меньше +1R и убыток −1R.

60 дней на прежних свечах: 73 входа, 41 цель, 31 стоп, 1 незавершённая
сделка; win rate 41/72=56.94%. Сумма известных исходов около +7.56R

сделка не включена. Независимо сверены хеши исходника и свечей, все 60
диапазонов H1, все 73 входа по базовой линии, отступы 0.03, первые касания
