## v11 — шортовый минимум «0» и сохранённая первая вершина LONG

Проверяется перенос только из сформированного шортового диапазона P1/P2
без обновления первого low, P2 ниже H1 при соблюдении «0», строгое
нарушение и допустимое равенство границе. Учитывается пропущенная
котировка пробоя «0» при наличии новой тени. После входа цена проверяется
по TP/SL, после стопа и новой H1 граница сбрасывается. SHORT с возникшей
P3 и незавершённая структура только из P1 исключение не получают.

Проверяется сохранение верхней P1 после соседнего нижнего свинга,
пропуск следующего более высокого low и выбор более низкой не соседней P2.
Обычные соседние пары по-прежнему отбрасываются полностью.
На реальных MEXC-свечах 24 августа: «0»=93.21, P1=96.33, P2=93.76,
цель=96.64, стоп=93.1175 и вход=94.87875 на баре 20:40 UTC+7, RR 1:1.

Тестовая оснастка восстановлена из официального PineTS v0.12.0,
Acorn 8.14.0 и Astring v1.9.0 через разрешённый GitHub. Используется
временный загрузчик Node.js TypeScript, сохраняющий исходные декораторы;
в файлах движка и условиях индикатора для тестирования подмен нет.
