# Проверка 22.10.2026

Исполняется непосредственно `sol_short_setup.pine`, без отдельной копии
алгоритма на JavaScript. Тесты: `tests/pine.test.mjs`, команда `npm test`.

Движок: [PineTS 0.12.0](https://github.com/LuxAlgo/PineTS/tree/v0.12.0),
commit `3dde7eb1d3bce92025e741cede148f437bb58d03` (официальный тег v0.12.0).
Среда проверки: Node.js 24.19.0.
Результат: **26 проверок прошли**, включая совпадение файла для загрузки
с проверяемым исходником.

Реестр npm здесь возвращал 403. Для фактического прогона использованы исходники
того же тега из GitHub и временный загрузчик TypeScript на базе Node.js.
Он разрешает импорты Acorn/Astring и сохраняет вызовы исходных декораторов;
это тестовая оснастка вне проекта, не подмена Pine-алгоритма.
В `package.json` зафиксирована соответствующая версия npm-пакета.
Установка через npm в этой среде не проверена.

Проверены:

- Сбор полного часа, отсутствие преждевременного/частичного диапазона.
- Часовые тени, границы 13:00–22:00 UTC+7 и цвета контура.
- Последовательность нижнего и верхнего фракталов, пробой первого лоя.
- Обновление H2 до пробоя и фиксация после него.
- Стоп F1.25, динамическая цель, вход как середина стопа и цели.
- Касание входа без закрытия выше него; отсутствие требования третьего фрактала.
- Пересчёт цели до входа и заморозка после; один сигнал.
- Отмена по H1 high и отбраковка стопа выше H1 high.
- Равенство границе не считается её обновлением.
- Консервативная обработка неоднозначного исторического low/high.
- Жизнь после 22:00, замена в 15:00 следующего дня, истечение при пропуске H1.
- Сохранение цен старого сигнала на границе публикации новой H1.
- Обновления одной открытой свечи: новый low, возврат к входу, одно
  событие `alertcondition`, отсутствие повторов и дальнейшего переноса цели.
- Понятная ошибка при выборе таймфрейма, отличного от M5.
- Восемь отдельных горизонтальных отрезков, без наклона при переносе цели.
- Фиксация правого края после сигнала, удаление отрезков при новой H1,
  отсутствие соединений с другим днём.
- Прозрачность и скрытие числовых серий для оповещения.

Не проверены: компиляция и отрисовка в Krytes, его настройка и доставка
оповещений, частота поступления цен и совпадение со встроенным Fractals
при дополнительном параметре «Периоды: 2».
На скриншотах первой версии от 22.10.2026 серии отображались с соединением
через пропуски. Это послужило основанием заменить видимые `plot` отдельными
горизонтальными `line` в v2. Отрисовка v2 в Krytes пока не подтверждена.
PineTS — отдельный движок; его прохождение тестов не заменяет эту проверку.
