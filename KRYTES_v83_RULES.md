# v83: вход по закрытию M5

База: проверенная v82 до чернового изменения подсчёта трёх свечей. Это изменение не включено из-за регрессии 16 октября; черновик v82 сохранён отдельно.

- Касание уровня расчётного RR 1:1 только разрешает вход после закрытия этой же пятиминутки. Исполнение по close, включая отскок от уровня.
- Структурные стоп и тейк не пересчитываются; фактический RR переменный. Свеча, затронувшая стоп, не даёт входа. Закрытие за стопом или целью не создаёт сделку.
- Закрытие должно попадать в окно [15:00, 00:00) Asia/Krasnoyarsk. Свеча, закрывающаяся в 00:00, не даёт нового входа. Открытая позиция сопровождается после полуночи.
- Вход не возникает на незакрытой свече. Движение внутри сигнальной свечи не считается результатом уже открытой позиции.
- Максимум две сделки; вторая только после стопа первой. Сценарии без входа не являются сделками.
- Годовой win rate для новой модели исполнения ещё не пересчитан.
